# Examples (`examples`)

## Overview

Repository-only material: none of this directory is shipped in the npm tarball, and `node --test` does not treat it as package content ([README.md](./README.md)). It records the plugin's end-to-end EGM verification run — brainstorm, draft and review of a low-stock alerts design against a scratch Python inventory fixture ([E2E-VERIFICATION.md](../E2E-VERIFICATION.md)) — so this directory is evidence, not production code.

## Subdirectories & Boundaries

- e2e-verification: [./e2e-verification/EGM.md](./e2e-verification/EGM.md) — blueprint for the recorded run: the fixture project contract in `fixture/`, the brainstorm and draft artifacts, and the five recorded review reports.
- Non-contract asset: [README.md](./README.md) — human-maintained overview of the run, its concessions, and reproduction steps.
